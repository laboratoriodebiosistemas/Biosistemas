# Sitio Web LMAB

Esta carpeta ya está lista para publicarse como sitio web estático.

## Contenido

- `index.html`: página principal
- `assets/`: imágenes del sitio

## Publicar en Netlify

1. Entra a [Netlify](https://www.netlify.com/).
2. Elige `Add new site` o `Deploy manually`.
3. Arrastra esta carpeta completa o súbela como proyecto.
4. Netlify detectará `index.html` automáticamente y te dará una URL pública.

## Publicar en Vercel

1. Entra a [Vercel](https://vercel.com/).
2. Crea un nuevo proyecto.
3. Sube esta carpeta.
4. Usa la configuración estática por defecto.

## Recomendación

La opción más rápida para este sitio es `Netlify`, porque no requiere configuración adicional.
